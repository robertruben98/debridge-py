# debridge-py

Python client for the deBridge DLN API — cross-chain swaps/orders across 19+ chains (EVM + Solana). Sync + async, Pydantic v2.

## Install

```bash
pip install debridge-py
```

The distribution is `debridge-py`; the import package is `debridge`.

## Quick start

```python
import debridge
```

See the [API reference](api.md) for the full surface.
